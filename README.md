# DON'T SLIP
A game where you dodge bananas by driving your bicycle on 3 roads.

DON'T SLIP is a game that I made entirely using python with all of the code in a singular file.
This project is not meant to be taken seriously, and it's code is not optimized at all.
I started this project at 17 because I was bored in my coding class and I wanted to learn how to use pygame.
It evolved into a project that also taught me how to use Git and how to debug my code.

Have fun wondering how my weird brain works while looking at the code, or just have fun playing the game!

# GAMEPLAY
DON'T SLIP has very simple gameplay.
When you press play, you will be put on one of three roads.
Move from road to road to avoid driving over a banana peel.
If you do drive over one, you will have to restart your run.
When you reach certain scores, the stage you are at will increase.
Every stage changes something about the gameplay, this could be speed or new obstacles you need to dodge.

# CONTROLS
DON'T SLIP has very few and very simple controls:
- Move lane
  - Left: left arrow key
  - Right: right arrow key
- Sprint: space (hold)
- Pause/Unpause: escape
